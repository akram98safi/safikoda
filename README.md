# Safikoda — IT & Full-Stack Portfolio

Welcome to the official repository for **Safikoda**, the professional portfolio of **Akram S. Safi**, a specialist in IT Support, Network Technician, and Full-Stack Web Developer based in Gaza, Palestine.

This website is a highly customized, bilingual, dynamic web application designed to showcase Akram's skills, professional experience, projects, and contact channels. It features an interactive, modern user interface with state-of-the-art styling and micro-interactions.

---

## 🚀 Key Features

*   **Interactive System Boot Preloader:** An immersive "system initialization" boot sequence animation introducing the user to the portfolio with options to skip.
*   **Dynamic Interactive Canvas Background:** A custom-rendered particle network background canvas that dynamically responds to mouse movements.
*   **Dual-Language Localization (English & Arabic):** Built-in real-time translation toggling. Automatically switches text alignment between LTR (Left-to-Right) for English and RTL (Right-to-Left) for Arabic.
*   **Sleek Dark Mode & Polished Light Mode:** A fully responsive theme manager that saves the user's preference in their browser local storage.
*   **Fluid Custom Cursor & Trailing Effect:** Custom smooth-following cursor ring and trailing cursor sparkles on desktops.
*   **Interactive 3D Tilt Cards:** Beautiful project cards that tilt in 3D perspective as the mouse moves over them.
*   **Filterable Projects Grid:** Projects organized by categories with instant filtering and dynamic "Live/Offline/Development" badges.
*   **Direct Contact & Support:**
    *   Contact form with input validation that opens preloaded email client templates.
    *   Support/Donation section with one-click copy functionality for Cryptocurrency addresses (BTC, ETH, USDT).

---

## 🛠️ Built With

*   **HTML5 & CSS3:** Semantic structure with modular CSS variables to handle theming, styling, and transitions.
*   **Vanilla JavaScript:** Lightweight, native JS handles all animations, translations, theming, dynamic particle canvas, timeline events, and form logic.
*   **Google Fonts:** Outfit, Outfit Arabic, and monospace typefaces for terminal and headers.

## ⚡ How to Run Locally

Since this is a standalone static web application, running it is extremely simple:

1.  Clone this repository:
    ```bash
    git clone https://github.com/akram98safi/safikoda.git
    ```
2.  Open the workspace directory:
    ```bash
    cd safikoda
    ```
3.  Double-click or open `index.html` in any web browser of your choice (Chrome, Firefox, Safari, Edge).
