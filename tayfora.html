✨ Core Capabilities & Features

🖼️ In-Browser Image Color Extraction

Extract 6 balanced dominant colors from any uploaded image using a custom HTML5 Canvas clustering algorithm that runs entirely in-memory with zero server uploads.

🎨 5 Color Theory Harmony Modes

Explore real color wheel mathematical harmonies including Analogous, Complementary, Triadic, Split-Complementary, and Monochromatic color spaces.

🔒 Color Locking & Instant Generation

Lock individual favorite color swatches while generating fresh complementary shades with a single click or spacebar press to build perfect custom palettes.

👁️ WCAG Contrast & Live Component Preview

Real-time WCAG accessibility text contrast rating coupled with an interactive live UI component preview card to test colors in real scenarios.

💾 Local Palette Archive & Storage

Save, organize, and manage your custom color collections in local browser `localStorage` without requiring accounts, logins, or tracking.

📦 One-Click Developer Token Export

Instant copy-paste code export formatted for CSS Variables, Tailwind CSS Config object, and JSON Design Tokens.

🔒 100% Privacy-First Guarantee

🛡️
Zero Server Uploads

Images uploaded for color extraction are processed locally in-memory using HTML5 Canvas and are never transmitted to any remote server.

🚫
No Accounts or Trackers

TAYFORA contains zero tracking scripts, analytics cookies, or account sign-up requirements. Your palette data belongs entirely to you on your device.
