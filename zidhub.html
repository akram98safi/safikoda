🚀 Core System Modules

🧠 Intelligent Skill Matching Engine

Calculates bidirectional skill overlap between students using proficiency weighted scoring (Expert=3, Intermediate=2, Beginner=1). Automatically excludes blocked users, pending requests, and current partners.

🔐 Real-Time Encrypted Messaging

Socket.IO 1-to-1 and group chat with server-side AES-256-GCM encryption at rest. Supports disappearing messages with automated TTL sweeper, presence status, and presigned direct R2 file uploads.

🎥 HD Audio & Video Call Integration

Embedded Jitsi-based 1-to-1 video rooms with Socket.IO signaling. Sandboxed media access with explicit CSP nonces, Permissions-Policy headers, and optional JWT-authenticated meeting rooms.

🎓 Courses & MIT OpenCourseWare

Curated courses with YouTube playlist proxies and direct access to thousands of MIT OpenCourseWare subjects. Includes progress tracking, lesson completion rewards (+25 XP), and ratings.

🎮 Comprehensive Gamification Engine

8-tier level system (0 → 5,000 XP) with 18 automated badges, weekly/monthly leaderboards, interactive trivia quiz hub powered by Open Trivia DB, and daily learning missions.

📱 Installable Progressive Web App (PWA)

Fully installable PWA with custom Web App Manifest, Service Worker caching strategies (`zidhub-static-v2`, `zidhub-cdn-v2`), app shortcuts, A2HS prompts, and offline capabilities.

🔄 Skill Exchange Lifecycle

State machine governing skill exchange agreements between university peers:

PENDING ──► ACCEPTED ──► DELIVERED ──► CONFIRMED ──► COMPLETED (+XP & Badge) │ │ ▼ ▼ REJECTED / CANCELLED DISPUTED (Escalates to Admin Moderation)

🛡️ Security & Enterprise Controls

🔑
Atomic Refresh Token Rotation

Short-lived 15-min access JWT combined with a rotating refresh-token family. Concurrent reuse triggers instant revocation.

🛡️
CSRF & Brute Force Defense

Double-Submit Cookie + HMAC token bound to `userId`. Automatic 5-minute lockout on 5 consecutive failed logins.

📦
Magic-Byte Media Verification

Centralized magic-byte binary inspection inside storage uploads prevents spoofed extensions or malicious polyglots.
